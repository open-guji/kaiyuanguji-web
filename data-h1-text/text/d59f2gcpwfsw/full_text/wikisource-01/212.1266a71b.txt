## 河傳

去去，
何處？
迢迢巴楚，
山水相連。
朝雲暮雨。
依舊十二峯前，
猿聲到客船。
 
愁腸豈異丁香結，
因離別，
故國音書絕。
想佳人花下，
對明月春風，
恨應同。

春暮，
微雨，
送君南浦，
愁斂雙蛾。
落花深處，
啼鳥似逐離歌，
粉檀珠淚和。 

臨流更把同心結，
情哽咽，
後會何時節？
不堪回首，
相望已隔汀洲，
艣聲幽。

## 【附錄一：詞家小傳】
; 溫庭筠 : 溫庭筠(812-870)，本名歧，字飛卿，太原祁（今山西祁縣）人。相貌奇醜，人稱「溫鍾馗」。初至京師，人士翕然推重，與當世詩人李商隱齊名，號「溫李」。然生性傲岸，恃才詭激，好譏訶權貴，取憎於時，尤為宰相令狐綯所不容，由是累年不第。宣宗大中十三年(859)始授隨縣尉，終仕國子助教。事迹見《舊唐書》卷一九○下、《新唐書》卷九一《溫大雅傳》附、《唐詩紀事》卷五四、《唐才子傳校箋》卷八、夏承燾《唐宋詞人年譜‧溫飛卿繫年》。

; 皇甫松 : 皇甫松（生卒年不詳），松一作嵩，字子奇，自號檀欒子，睦州新安（今浙江淳安）人。父湜，唐著名古文家，官至工部郎中。松為牛僧孺表甥，工詩詞，亦擅文，然久試進士不第，終生未仕。光化三年十二月(901年初)，韋莊奏請追賜溫庭筠、皇甫松等人進士及第，故《花間集》稱為「皇甫先輩」，蓋唐人呼進士為先輩。事迹見《唐摭言》卷一○、《唐詩紀事》卷五三。

; 韋莊 : 韋莊(836-910)，字端己，長安杜陵（今陝西西安市東南）人。韋應物四世孫。廣明元年(880)，應舉長安，值黃巢入破京師，莊目睹戰亂，遂於中和三年(883)，在洛陽作《秦婦吟》詩，時人因號曰「《秦婦吟》秀才」。後遊江南諸地，昭宗景福二年(893)，入京應試，次年登進士第，為校書郎。乾寧四年(897)，李詢辟為判官，奉使入蜀。光化三年(900)，擢左補闕。十二月，奏請追賜李賀、皇甫松、陸蒙龜等進士及第。天復元年(910)，入蜀依王建，為掌書記。及朱全忠篡唐自立，乃勸王建稱帝，定開國制度，為吏部侍郎兼平章事。蜀高祖武成三年(910)八月，卒於成都，謚文靖。事迹見《蜀檮杌》卷上、《唐詩紀事》卷六八、《唐才子傳校箋》卷一○、《十國春秋》卷四○本傳，另參夏承燾《唐宋詞人年譜‧韋端己年譜》。

; 薛昭蘊 : 薛昭蘊（生卒年不詳），字里無考，《花間集》稱為「薛侍郎」。新舊《唐書》有《薛昭緯傳》，稱其乾寧中為禮部侍郎，《北夢瑣言》卷四又謂昭緯愛唱《浣溪沙》詞。王國維《庚辛之間讀書記‧跋覆宋本〈花間集〉》據之疑為薛昭緯。其說云：「今此集載昭蘊詞十九首，其八首為《浣溪沙》；又稱為薛侍郎，恐與昭緯為一人。緯、蘊二字俱從系，必有一誤也。」俞平伯疑其非是，謂「史載昭緯卒於唐末，而《花間集》列昭蘊於韋莊、牛嶠間，當為前蜀時人。」（《唐宋詞選釋》上卷）陳尚君《花間詞人事輯》承王說以為「當即薛昭緯」，並「另舉數據，以成其說」。然終無確乎不拔之證。

; 牛嶠 : 牛嶠（生卒年不詳），《舊唐書》作蟜，恐誤。字松卿，一字延峰。其先安定鶉觚（今甘肅靈臺）人，後徙狄道（今甘肅臨洮）。牛僧孺之孫，牛叢之子。乾符五年(878)，登進士第。歷官拾遺、補闕、尚書郎。大順二年(891)，王建鎮蜀後，辟為判官。及前蜀開國，拜給事中，卒。事迹見《唐詩紀事》卷七一、《郡齋讀書志》卷一八、《唐才子傳校箋》卷九、《十國春秋》卷四四本傳。

; 張泌 : 張泌（生卒年不詳），字里無考，《花間集》列諸牛嶠、毛文錫之間，稱「張舍人」。南唐時別有張泌（一作「佖」）者，初官句容尉，後主徵為監察御史，官內史舍人，後隨後主歸宋，及見後主之卒。前人多以為《花間》詞作者。近人胡適疑之，謂「此說殊多謬誤。《花間集》結集於九四○年，其時南唐建國不及四年。後主嗣位在九六一年，相距二十餘年，而《花間集》裏已稱張舍人泌了。」並謂「《花間集》稱人官爵皆是結集時的官爵，故和凝只稱『學士』，而不稱『相』。」（《胡適選注的〈詞選〉》）俞平伯亦謂南唐時之張泌，「及見李煜之死，則已在九七八年之後，距《花間集》成書遲約四十年。且《花間集》不收南唐詞，自非一人也。」（《唐宋詞選釋》）陳尚君撰《花間詞人事輯》疑與唐末詞人張曙為同一人，皆無碻證，錄以備考。

; 毛文錫 : 毛文錫（生卒年不詳），字平珪，高陽（今屬河北）人，唐太僕卿毛龜範子。文錫通音律，能詩工詞，時名頗重。年十四，登進士第。唐亡，仕前蜀，任中書舍人、翰林學士，與貫休時有唱和。旋遷翰林學士承旨。永平四年(914)八月，遷禮部尚書，判樞密院事。通正元年(916)八月，兼文思殿大學士。拜司徒。天漢元年(917)八月，貶茂州司馬。或云前蜀亡後，隨王衍入洛而卒。一說未幾復事孟氏，與歐陽炯等五人以小詞為後蜀主所賞。事迹據《十國春秋》本傳，另參陳尚君《花間詞人事輯》。

; 牛希濟 : 牛希濟(872?-?)，狄道（今甘肅臨洮）人，嶠之兄子。遭遇世亂，流寓入蜀，依季父嶠。仕前蜀為起居郎，累官翰林學士、御史中丞。前蜀亡，隨後主入洛。天成初，後唐明宗命作《蜀主降臣唐詩》，但述數盡，不謗君親，為明宗所稱賞，拜雍州節度副使。其後事迹無考。事迹據《鑒誡錄》卷七、《太平廣記》卷一五八、《新編分門古今類事》卷七、《十國春秋》卷四四本傳。

; 歐陽炯 : 臨陽炯(896-971)，益州華陽（今四川雙流）人。少事前蜀王衍為中書舍人。前蜀亡，隨王衍至洛陽。補秦州從事。孟知祥鎮蜀，炯復回成都。知祥稱帝，任中事舍人。後主孟昶廣政三年(940)四月，官武德軍節度判官，為趙崇祚編《花間集》作叙。十二年(949)拜翰林學士。次年，知貢舉，判太常寺。後遷禮部侍郎，領陵州刺史，轉吏部侍郎，加承旨。二十四年(961)五月，拜門下侍郎兼戶部尚書、平章事、監修國史。 宋乾德三年(965)元月，後蜀亡，炯隨昶至汴京。六月宋除炯為右散騎常侍，俄充翰林學士，轉左散騎常侍。後分司西京。開寶四年(971)卒。年七十六。《宋史》卷四七九、《十國春秋》卷五六有傳。

; 和凝 : 和凝(898-955)，字成績，鄆州須昌（今山東東平）人。梁乾化四年(914)舉明經。貞明二年(916)登進士第 。後為宣義軍節度使賀瓖從事，歷鄆、鄧、洋三府從事。後唐明宗天成三年(928)拜殿中侍御史。歷禮、刑二部員外郎，改主客員外郎、知制誥，尋充翰林學士，遷主客郎中。長興四年(933)，知貢舉，所取多才名之士，時議以為得人。後歷中書舍人、工部侍郎，皆充學士。後晉天福二年(937)，改禮部侍郎，拜端明殿學士，兼判度支，改戶部侍郎，復為翰林學士承旨。五年，為中書侍郎平章事，後加右僕射。開運二年(945)為左僕射。後漢天福十二年(947)除太子太保，封魯國公。後周廣順元年(951)，為太子太傅。顯德二年(955)七月卒。年五十八,詔贈侍中。事迹見《北夢瑣言》卷六、《舊五代史》卷一二七、《新五代史》卷五五本傳。

; 顧敻 : 顧敻（生卒年不詳），字里無考。前蜀通正元年(916)，以小臣給事內庭，會大禿鶖鳥翔於摩訶池上，敻作詩刺之，禍幾不測。久之，擢茂州刺史。已而復事後蜀孟知祥，累官至太尉。事迹見《鑒誡錄》卷六、《十國春秋》卷五六本傳。

; 孫光憲 : 孫光憲(?-968)，字孟文，號葆光子，陵州貴平（今四川仁壽）人。家世業農，廣交蜀中文士。曾為陵州判官。後唐天成元年(926)，避地江陵，梁震薦於荊南高季興，為掌書記。歷仕從誨、保融、繼沖三世。累官荊南節度副使、檢校秘書監兼御史大夫。宋乾德元年(963)二月，宋軍假道荊南，光憲勸高繼沖盡獻荊南三州之地。入宋後，授黃州刺史。在郡有治聲。乾德六年(968)，宰相薦光憲為學士，未召，會卒。事迹見《新五代史》卷六九《南平世家》、《宋史》卷四八三、《十國春秋》卷一○二本傳。

; 魏承班 : 魏承班(?-925)，許州（今河南許昌）人。其父魏弘夫，王建收為養子，改名王宗弼，承班亦從其父改名王承班。前蜀後主光天元年(918)六月，宗弼剪除唐文扆後，以兼中書令秉政。承班為駙馬都尉、太尉。咸康元年(925)十一月，後唐軍攻蜀，宗弼叛蜀歸唐，據成都，自稱留後。承班奉父命賂唐軍。唐軍入成都後，族誅王宗弼家，承班亦罹難。事迹據《九國志》卷九、《新五代史》卷六三、《十國春秋》卷三九《王宗弼傳》，並《資治通鑑》、《錦里耆舊傳》等。

; 鹿虔扆 : 鹿虔扆（生卒年不詳），字里無考。事孟蜀為永泰軍節度使，進檢校太尉，加太保。事迹見《茅亭客話》卷三、《十國春秋》卷五六。

; 閻選 : 閻選（生卒年不詳），字里無考，故布衣也。酷善小詞，時人稱為閻處士。事迹見《十國春秋》卷五六本傳。

; 尹鶚 : 尹鶚（生卒年不詳），錦城（今四川成都）煙月之士。工詩詞，與賓貢李珣友善。仕前蜀為校書郎。《花間集》卷九稱「尹參卿鶚」，參卿為參佐官之敬稱，非具體官守。事迹見《鑒誡錄》卷四、《十國春秋》卷四四本傳。

; 毛熙震 : 毛熙震（生卒年不詳），字里無考。仕蜀，官秘書郎。好書能詞。事迹見《花間集》卷九、《茅亭客話》卷三。

; 李洵 : 李洵（生卒年不詳），字德潤，梓州（今四川三台）人。其先為波斯人，後入蜀中。其妹舜絃，為前蜀王衍昭儀。珣少小苦學，有詩名，以秀才豫賓貢，事蜀主王衍，與成都才士尹鶚相善。國亡，不仕。事迹見《鑒誡錄》卷四、 《茅亭客話》卷二、《十國春秋》卷四四本傳。
